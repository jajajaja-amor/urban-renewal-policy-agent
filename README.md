# 城市更新政策匹配智能体

面向设计师和甲方业务团队的城市更新项目政策研判助手。当前产品设计范围为国家政策和北京市政策，目标是从项目任务书或投标文件出发，形成可核对的项目画像、政策匹配建议和北京同类案例参考。

## 当前阶段

项目处于第一阶段 MVP 架构设计。政策自动采集与结构化入库工作流作为第二阶段的待接入能力。
